# Rellenador EX-17

Aplicación de escritorio desarrollada para facilitar y automatizar el
rellenado del formulario EX-17.

## Versión

**v1.0.0**

## Funcionalidades

- Carga de un formulario EX-17 previamente cumplimentado.
- Carga de una resolución de concesión.
- Extracción automática del NIE.
- Validación del NIE.
- Copia automática de datos al nuevo formulario EX-17.
- Rellenado automático de determinados campos.
- Generación del nuevo documento PDF.
- Nombre automático para los documentos generados.
- Selección de la carpeta de destino.

## Configuración avanzada

La configuración avanzada se encuentra actualmente en desarrollo.

**Próximamente en la versión 2.0.**

## Tecnologías utilizadas

- Java 21
- JavaFX 21
- Apache PDFBox 3
- Maven

## Requisitos

La versión instalable para Windows incluye el entorno necesario para
ejecutar la aplicación.

No es necesario instalar Java por separado.
